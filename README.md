# AITK Dataset Editor

[ai-toolkit](https://github.com/ostris/ai-toolkit) 의 데이터셋 폴더를 직접 편집하는 보조 도구입니다.
ai-toolkit UI 와 같은 폴더/파일 규칙(이미지 + 같은 이름의 `.txt` 캡션)을 사용하므로 두 도구를 함께 써도 됩니다.

- **백엔드**: Python 3.10+ / FastAPI / Pillow (uv 로 관리)
- **프론트엔드**: React + TypeScript + Vite

## 실행

필요: [uv](https://docs.astral.sh/uv/), Node.js 20+ (프론트엔드 빌드용)

```bash
./run.sh          # Windows: run.bat
```

처음 실행하면 프론트엔드를 빌드한 뒤 `0.0.0.0:8665` 에서 서버를 띄웁니다 (접속: http://localhost:8665).
`HOST`, `PORT` 환경변수로 주소를 바꿀 수 있습니다 (예: `HOST=127.0.0.1 PORT=9000 ./run.sh`).

개발 모드(자동 리로드): `./dev.sh` → http://localhost:5173

## 기능

### 설정
- ai-toolkit 설치 경로를 입력하면 ai-toolkit UI 와 동일한 규칙으로 데이터셋 폴더를 찾습니다.
  1. `<ai-toolkit>/aitk_db.db` 의 `Settings.DATASETS_FOLDER` (ai-toolkit UI 설정에서 바꾼 값, 읽기 전용으로 조회)
  2. 없으면 `<ai-toolkit>/datasets`
- 필요하면 데이터셋 폴더를 직접 지정할 수도 있습니다.
- 설정은 `backend/config.json` 에 저장됩니다.

### 데이터셋 조회/추가/삭제/편집
- 데이터셋 목록(파일 수, 캡션 수, flip 수), 생성, 이름 변경, 삭제
  - 새로 만들 때 이름은 ai-toolkit 과 같은 규칙으로 정리됩니다 (소문자, 영숫자 외 문자는 `_`).
  - 이름 변경은 목록 또는 데이터셋 화면 제목 옆 ✎ 버튼으로 합니다. 대소문자·한글·`-`·`.` 은 유지되고
    그 외 문자는 `_` 로 바뀌며, 최종 폴더 이름을 미리 보여줍니다. 대소문자만 바꾸는 것도 가능합니다.
  - 이름을 바꾸면 해당 경로를 쓰던 ai-toolkit 학습 작업(job)의 데이터셋 경로도 직접 바꿔야 합니다.
- **데이터셋 합치기**: 목록에서 체크박스로 2개 이상 고른 뒤 "선택한 N개 합치기" → 새 데이터셋으로 이미지·캡션 복사 (원본 유지)
  - 이름이 겹칠 때: 겹치는 것만 `데이터셋이름_` 접두사 / 모두 접두사 / 먼저 것 유지(목록 순서, ↑↓ 로 변경)
  - 원본과 `_flip` 은 한 묶음으로 처리되어 연결 유지, `_flip` 제외 옵션, 미리보기(개수·겹치는 이름), 백그라운드 작업
- 데이터셋 복제: 목록의 "복제" 또는 데이터셋 화면의 "⧉ 복제"
  - 기본 이름은 `이름_copy` (이미 있으면 `_copy2`, `_copy3` …), 이름 변경과 같은 규칙으로 정리
  - 이미지·캡션·`_controls` 를 복사하고 ai-toolkit 캐시 폴더(`*_cache`)는 제외. 옵션으로 `_flip` 파일 제외 가능
- 이미지/영상/캡션(.txt) 업로드 (버튼 또는 드래그 앤 드롭)
- 캡션 바로 편집 (포커스 해제 또는 Ctrl+Enter 시 저장)
- 데이터셋 화면에서 삭제하면 원본과 `_flip` 이 함께 삭제됩니다 (`a.png` 삭제 → `a_flip.*` 도, `a_flip.png` 삭제 → `a.*` 도). 확인 창에 함께 지워지는 개수가 표시됩니다
- 크게 보기(←/→ 이동, 마우스 휠 확대/축소 · 드래그 이동 · 더블클릭/0 원래 크기), 단일/다중 선택 삭제 (Shift+클릭 범위 선택) — 이미지와 캡션이 함께 삭제됨
- 필터: 전체 / 원본 / flip / 캡션 없음, 파일명·캡션 검색
- **접두사/접미사 일괄 추가**: 선택한 항목(선택이 없으면 보이는 항목 전체)의 파일명에 접두사·접미사를 붙임
  - 캡션(.txt) 함께 변경, 연결된 원본/`_flip` 도 함께 (접미사는 `_flip` 앞에 붙어 연결 유지: `a_flip.png` → `a_v2_flip.png`)
  - `<데이터셋>_pattern` 의 패턴 이미지도 함께 변경, 바꾸기 전 미리보기, 기존 파일과 이름이 겹치면 아무것도 바꾸지 않음

### 두 데이터셋 비교
- 데이터셋 선택 상자에 입력하면 후보가 바로 필터됩니다 (공백으로 여러 단어 검색, ↑/↓ + Enter 선택, Esc 취소)
- A, B 데이터셋을 고르면 **파일명(확장자 제외)** 이 같은 것을 짝으로 묶습니다.
  (`img_01.jpg` ↔ `img_01.png` 는 짝) 옵션: 대소문자 무시, 하위폴더 무시
- 탭: **짝있음 / 짝없음·A에만 / 짝없음·B에만**
- `_flip` 파일은 비교에서 제외되며, 비교 화면에서 삭제하면 같은 이름의 `_flip` 파일(과 캡션)도 함께 삭제됩니다
- 짝없는 데이터 삭제: **A만 / B만 / 둘다**, 또는 짝없음 탭에서 골라서 선택 삭제
- 짝있는 데이터도 선택(체크박스, Shift+클릭 범위 선택)해서 **A만 / B만 / 둘다** 삭제 — 나란히/겹침 그리드/큰 겹쳐보기 모두 지원
- 짝있는 데이터 **겹쳐보기**
  - 나란히 / 겹치기(B 투명도 조절) / 슬라이더(드래그) / 차이(difference) / 깜빡임 / A만 / B만
  - 해상도가 다르면 표시, "B를 A 크기에 맞춤" 옵션
  - 양쪽 캡션도 그 자리에서 편집 가능 · 단축키 ←/→, 1~7
  - 마우스 휠 확대/축소(커서 기준), 드래그 이동, 더블클릭/0 원래 크기. 나란히 모드는 A·B 가 함께 확대되고, 슬라이더 모드에서는 Space+드래그(또는 휠 클릭 드래그)로 이동
- **겹침 그리드**: 짝있음 탭에서 모든 짝을 썸네일 단위로 한꺼번에 겹쳐 봅니다.
  - 겹치기(투명도) / 슬라이더 / 차이 / 깜빡임 / A만 / B만 — 하나의 컨트롤로 모든 타일에 동시 적용
  - **겹치기 모드에서 "💾 보이는 대로 새 데이터셋 저장"**: 현재 투명도·"B를 A 크기에 맞춤" 설정 그대로 원본 해상도로 합성해
    새 데이터셋을 만듭니다 (선택한 짝이 있으면 그 짝만, 없으면 보이는 짝 전체). 파일 이름·하위폴더·형식은 A 를 따르고,
    캡션은 A / B / 없음 중 선택. 영상은 제외됩니다.
  - 슬라이더 모드에서는 타일 위에 마우스를 올려 개별 조절, 타일 클릭 시 큰 겹쳐보기로 이동
  - 보기 모드와 설정은 브라우저에 기억됩니다

### 패턴 가이드 (두 번째 컨트롤 이미지) 픽셀 에디터 — 데이터셋 화면 각 항목의 "▦ 패턴"
- 캔버스 크기 변경 시 3×3 기준점으로 기존 픽셀을 고정할 위치를 선택 (반대쪽이 늘어나거나 잘림, 가운데 = 양쪽 균등)
- W×H 픽셀 **타일**(캔버스 크기 1~256)을 그리면, 설정한 **저장 크기(px)로 꽉 차게 늘려서**(셀 경계가 선명하게)
  `<데이터셋>_pattern/<같은 이름>.png` 에 저장 (데이터셋이 없으면 자동 생성) → ai-toolkit `control_path_2` 용
- 빈 칸은 항상 흰색(#ffffff). 색 프리셋 5개: #ffffff, #b9b543, #666666, #a34f4f, #5768bc (단축키 1~5)
- 도구: 펜(B) / 지우개(E, 우클릭 = 흰색) / 채우기(G) / 스포이드(I), 타일 순환 이동, 되돌리기(Ctrl+Z), 저장(Ctrl+S)
- **줄 가이드**: 캔버스 위쪽/왼쪽의 점선 칸을 칠하면 해당 세로줄/가로줄 전체가 같은 색으로 칠해짐 (드래그로 여러 줄,
  우클릭은 흰색). 가이드 칸은 실제 픽셀이 아니며, 줄이 한 색이면 그 색, 섞여 있으면 빗금으로 표시
- 저장 크기는 데이터셋별로 기억되어 같은 데이터셋의 다음 데이터에도 기본값으로 들어감 (처음엔 원본 이미지 크기)
- 오른쪽 **원본 보기**: 원본 이미지를 휠로 확대 / 드래그로 이동
- 우상단 **‹ 이전 / 다음 ›**: 저장하지 않은 변경은 저장 후 이동해 연속으로 편집
- **기존 패턴에서 가져오기**: 데이터셋에서 쓰인 타일을 **중복 없이** 썸네일·사용 개수와 함께 보여주고 골라서 복제
- 패턴 정의는 PNG 안에 저장되어 다시 열면 편집 가능. `_flip` 항목이 있으면 좌우 반전된 가이드도 자동 저장

### 불투명 영역 마스크 데이터셋 생성 (데이터셋 화면 "🎭 불투명 영역 마스크")
- 각 이미지의 불투명한 부분(알파 > 임계값, 기본 16)은 흰색, 투명한 부분은 검은색인 마스크 PNG 를 같은 이름(하위폴더 유지)으로 저장
- 경계 조정(+ 확장 / − 축소 px), `_flip` 포함 여부, 한 장씩 실시간 미리보기, 확인용 미리보기 데이터셋(선택)
- 완료 후 투명 영역이 없는 이미지(전부 흰색) / 완전히 투명한 이미지(전부 검은색) 목록 표시

### 외벽 마스크 데이터셋 생성 (비교 화면 "🎭 마스크 데이터셋 생성")
- `make_wall_masks.py` 와 같은 알고리즘(결과 픽셀 동일): 칠해진 **타깃**과 흰 건물 **컨트롤**을 비교해
  색이 바뀐 픽셀(RGB 채널 차이 > 임계값, 양쪽 모두 불투명)을 외벽으로 보고 잡티 제거 → 빈틈 메우기 → 경계 팽창,
  배경(타깃 투명)은 제외. 흰색=외벽 / 검은색=나머지 PNG 를 타깃과 같은 이름으로 저장 (ai-toolkit `mask_path` 용)
- A/B 중 어느 쪽이 타깃인지 선택, 모든 옵션(색 차이 40, 알파 16, 잡티 1, 빈틈 4, 팽창 8, 컨트롤 없는 타깃 처리)을
  조절하며 한 쌍씩 **실시간 미리보기**(외벽 비율 표시)
- 선택적으로 확인용 미리보기 데이터셋(왼쪽 원본, 오른쪽 자홍색 = 마스크)도 생성
- 완료 후 컨트롤 없는 타깃 / 타깃 없는 컨트롤 / 확인이 필요한 이미지(외벽 비율 3% 미만·95% 초과, 리사이즈) 목록 표시
- 원본 스크립트와의 픽셀 비교 테스트: `WALLMASK_SCRIPT=/path/make_wall_masks.py uv run pytest tests/test_wallmask.py`

### 좌우 반전 (x축 flip)
- **flip 추가**: 데이터셋의 모든 원본 이미지에 대해 `이름_flip.확장자` 로 좌우 반전 이미지를 만들고,
  캡션 파일도 `이름_flip.txt` 로 복사합니다. 이미 있는 flip 은 건너뛰고, `_flip` 파일을 다시 뒤집지는 않습니다.
  (형식 유지, EXIF 회전 반영, ICC 프로필 유지, JPEG 품질 95. 영상/GIF 는 건너뜀)
- **_flip 모두 제거**: 파일명이 `_flip` 으로 끝나는 모든 미디어와 캡션을 삭제합니다.

### BiRefNet → SAM 데이터셋 변환 (변환 메뉴)
- 입력: BiRefNet/DIS5K 형식 — 한 데이터셋 안의 `im/`(이미지) + `gt/`(같은 이름의 흑백 마스크) 폴더,
  또는 이미지 데이터셋 + 마스크 데이터셋(파일 이름으로 짝)
- 출력: SAM / SAM 2 학습용 **SA-1B 형식**의 새 데이터셋 — `이름.jpg` + `이름.json`
  (`image{image_id,width,height,file_name}`, `annotations[{segmentation(COCO RLE), area, bbox, point_coords, crop_box, predicted_iou, stability_score}]`)
- 옵션: 마스크 임계값(기본 128), 떨어진 영역을 별도 객체로 분리(+최소 면적), JPG 변환, 빈 마스크 제외
- 프롬프트 점은 객체 안쪽에서 경계로부터 가장 먼 픽셀, 마스크 크기가 이미지와 다르면 이미지 크기에 맞춤
- RLE 인코딩은 pycocotools 와 동일한 결과인지 테스트로 검증합니다. 원본 데이터셋은 바뀌지 않습니다.

## 참고
- 썸네일은 `backend/.cache` 에 캐시되며 원본 데이터셋 폴더에는 아무것도 추가하지 않습니다.
- 숨김 파일과 `_controls` 폴더는 ai-toolkit 과 마찬가지로 무시합니다.
- 서버는 기본적으로 `0.0.0.0` (모든 네트워크 인터페이스)에서 열립니다. 인증 기능이 없으므로 같은 네트워크의 누구나 접근할 수 있습니다. 로컬에서만 쓰려면 `HOST=127.0.0.1` 로 실행하세요.
